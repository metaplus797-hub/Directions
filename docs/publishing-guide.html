レベル 1　いちばん抽象

ひとことで言うと

Vercel

アプリを置いて、24時間動かしてくれる場所

お店でいうと: 管理人つきの貸し店舗

Cloudflare

そのアプリの住所（ドメイン）を管理する場所

お店でいうと: 住所の登記所と住所録

レベル 2

お店にたとえると

いまは開発者のPCで localhost:8000 を開いて動かしています。自宅のキッチンで料理ができている状態です。食べられるのは家の中の人だけで、PCを閉じればお店も閉まります。

一般公開するとは、お店を出すことです。そのためには次の3つが必要です。

お店でいうとWebでいうと担当
店舗（建物・厨房・店員）アプリを動かすコンピューターVercel
住所と看板ドメイン（例: nav.example.com）Cloudflare
「その住所はどこ？」に答える住所録DNSCloudflare

Vercel は管理人つきの貸し店舗

  • 建物の建設・掃除・警備は Vercel がやってくれます。サーバーの管理はいりません。
  • レシピ（コード）を GitHub に置くと、自動で厨房にセットしてくれます。
  • 店員はお客さんが来たときだけ出勤します。暇な時間の人件費がかからないので安く済みます。
  • メニュー表や写真は全国の棚に置いてあり、お客さんの近くから手渡されます。

Cloudflare は住所の登記所と住所録

  • 住所（ドメイン）を原価で買えます。
  • 「nav.example.com は Vercel にあるお店です」と案内してくれます。

住所とお店を別々にしておく理由

お店を Vercel から別の場所に移すことになっても、住所録の行き先を書き換えるだけで済みます。お客さんは同じ住所でたどり着けます。

このアプリでは、NFCタグに URL を書き込みます。URL を書いたタグなら、iPhone でも Android でも、かざすだけでブラウザが開きます。タグには住所が物理的に書き込まれるので、仮の住所（xxx.vercel.app）のままにしておくと、引っ越しのたびにタグを全部書き直すことになります。最初に自分の住所を取っておくのはこのためです。

レベル 3

用語を少しだけ

ドメイン
nav.example.com のような、人が読める住所。毎年料金を払って借ります。
DNS
ドメインを、コンピューターの本当の住所（IPアドレスという数字）に変える電話帳。Cloudflare が担当します。
HTTPS
通信の暗号化。URL が https:// で始まり、鍵マークが付きます。ページの中でNFCを読み取る機能（Web NFC）は HTTPS でないと動きません。Vercel が無料で自動的に設定します。
デプロイ
コードを公開用のコンピューターに載せること。
サーバーレス
常に動いているサーバーを持たず、アクセスが来たときだけプログラムを起動する仕組み。しばらく使われないと眠るので、その直後のアクセスだけ少し遅くなることがあります。
CDN
世界各地にあるコピー置き場。画面のファイルや画像のように中身が変わらないものを、利用者の近くから配ります。

レベル 4

タグをかざしてから、経路が出るまで

利用者が7階の W705 の前にあるタグ（地点ID F7-3）にスマホをかざし、W701 への道を調べる場面です。

  1. タグには https://nav.example.com/?loc=F7-3 のような URL が書いてあります。かざすとブラウザが開きます。
  2. スマホが住所録（Cloudflare）に「nav.example.com はどこ？」と聞き、Vercel の場所を教わります。
  3. Vercel の画面置き場から、画面と地図画像・写真を受け取ります。いまの frontend フォルダの中身です。
  4. 画面が経路計算（FastAPI）に問い合わせます。FastAPI は呼ばれたときだけ起動し、経路を計算して返したら、また眠ります。
  5. 地図に赤い矢印で経路が描かれます。

Cloudflare が出てくるのは2番の一瞬だけです。それ以外はすべて Vercel が担当します。

レベル 5　いちばん具体

チームがやる作業と費用

先にやること: エンジニアが、コードを公開向けに少し直します（画面のファイルを public フォルダに移す、など）。技術的な作業なので、ここでは説明を省きます。

最初の1回だけ

  1. Cloudflareアカウントを作り、ドメインを買います（例: example.com）。
  2. VercelGitHub アカウントでログインし、「Add New → Project」から metaplus797-hub/Directions を選びます。リポジトリの持ち主（metaplus797-hub）が Vercel との連携を許可する必要があります。
  3. VercelRoot Directory に fastapi-project を指定して Deploy を押します。xxx.vercel.app という仮の住所で公開されます。
  4. VercelSettings → Domains に nav.example.com を追加します。住所録に書く値が表示されます。
  5. CloudflareDNS に、4番で表示された値を1行追加します。雲のマークはグレー（DNS only）にします。
  6. 完了数分後に https://nav.example.com で開けるようになります。

公開したあとの更新

  • Cloudflare はほとんど触りません。年1回のドメイン更新くらいで、自動更新にもできます。
